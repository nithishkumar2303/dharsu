DHARSUUU BIRTHDAY WEBSITE
=========================

Open index.html in a browser to preview.

DEPLOY TO VERCEL:
1. Go to https://vercel.com/
2. Create a new project.
3. Upload this folder / connect the GitHub repo.
4. Deploy.

To customize:
- Edit the text directly in index.html.
- Replace images inside assets/ while keeping photo1.jpg ... photo8.jpg.
- If you want music, add an audio file and wire it into index.html.

The site is intentionally static: no backend, no database, no build step.
