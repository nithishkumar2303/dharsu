DHARSUUU BIRTHDAY WEBSITE
=========================

Open index.html in a browser to preview. The page is static and does not need a build step or backend.

CUSTOMIZE
- Edit the birthday message and captions directly in index.html.
- Replace the images in assets/ while keeping the filenames photo1.jpg through photo10.jpg.
- The photo captions and alt text are in the matching figure blocks in index.html.
- If you add music later, use a play button rather than autoplay so it works reliably on phones.

DEPLOY TO VERCEL
1. Go to https://vercel.com/.
2. Create a new project and connect this GitHub repository (or upload the dharsuuu_birthday folder).
3. Deploy it as a static site.

PRIVACY
The opening screen is a visual reveal, not a password. Anyone with the published link may be able to view the page and photos, so only deploy it if you are comfortable sharing those images.
